# Prompt Kütüphanesi

En sevdiğin AI prompt'larını kaydet, kategorize et ve tekrar kullan.

## Özellikler

- 📝 Prompt ekleme, düzenleme ve silme
- 🏷️ Kategoriye göre filtreleme
- 🔍 Prompt arama
- 📋 Tek tıkla panoya kopyalama
- 💾 Local Storage ile kalıcı kayıt
- 🌙 Karanlık tema

## Kullanım

Siteyi aç, prompt'larını ekle, kategorize et ve ihtiyacın olduğunda kopyala. API gerekmez, her şey tarayıcında çalışır.
